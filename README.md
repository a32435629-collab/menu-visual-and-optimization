# Menu Visual & Optimization

Модульный лаунчер (меню) для скриптов Roblox, написанный на Luau. 
Собирает все модули в один файл для удобного запуска через экзекуторы (например, Solara).

## 📂 Структура проекта

- `main.lua` — точка входа (вызывает меню).
- `menu.lua` — графический интерфейс (кнопки, окно).
- `src/` — скрипты, которые скачивают и запускают модули (`visual`, `render`, `graphics`) с GitHub.
- `build.bat` — сборщик, который склеивает все файлы в один.
- `dist/` — папка, куда сохраняется готовый собранный скрипт.

## 🛠️ Как собрать

1. Убедись, что все `.lua` файлы на месте.
2. Запусти **`build.bat`** (двойным кликом).
3. В папке `dist/` появится файл **`launcher.lua`**.

## 🚀 Как использовать

1. Открой файл `dist/launcher.lua` любым текстовым редактором (Блокнот, Notepad++).
2. Скопируй **весь код** из этого файла.
3. Открой Roblox, запусти **Solara** (или другой экзекутор).
4. Вставь код в консоль и нажми **Execute**.
5. Появится меню с кнопками. При нажатии лаунчер сам скачает нужный модуль с GitHub и запустит его.

## 📦 Модули

Ссылки на модули прописаны в файлах `src/start_*.lua`. 
Если ты обновил код модуля (например, `visual.lua`) на GitHub, тебе не нужно обновлять лаунчер — он всегда качает самую свежую версию.
